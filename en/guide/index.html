Guide

How to connect an account, add a ready-made shortcut and build your own from the FakturyRadar actions.

Contents: KSeF account · Ready-made shortcuts · Actions · Choosing invoices · Formats · Template · Variables

KSeF account

  1. Sign in to KSeFThrough login.gov.pl in the KSeF Taxpayer App: with mObywatel, e-dowód, online banking or Profil Zaufany.
  2. Open "Tokeny" and choose "Generuj token"You will find them in the site menu.
  3. Name it and select viewing invoicesFor example, "FakturyRadar".
  4. Copy the token and paste it into FakturyRadarWith your company's tax ID (NIP). The token is shown only once. Do not keep it in your notes.
  5. Tap "Test login"When the connection works, save the account.

The token is encrypted in this device's keychain and never goes to iCloud. Add the account separately on each device that should run automations. You can add several accounts, for example for several companies.

Ready-made shortcuts

The Automations tab has five shortcuts. Tap one to add it to the Shortcuts app, then set up its automation, for example at a fixed time or when you arrive somewhere.

  • Morning invoice review: a notification listing new purchase invoices.
  • Check invoices when I get to work: the same, when you arrive at a chosen place.
  • Morning invoices by email: PDFs of new invoices in an email.
  • Archive in iCloud Drive: PDFs of new invoices in the FakturyRadar folder.
  • Monthly summary by email: last month's invoices with totals.

After adding a shortcut

iOS adds the shortcut with its automation off, and only you can turn it on.

Shortcuts that run at a set time

  1. Tap EditShortcuts first shows a preview of the shortcut.
  2. Open the first stepTap the arrow next to the time.
  3. Turn on AutomationThe shortcut then runs on its own.

Check invoices when I get to work

  1. Tap EditShortcuts first shows a preview of the shortcut.
  2. Choose your work locationTap Location in the first step.
  3. Turn on AutomationTap the arrow next to the location to see the switch.

Shortcuts that send email

  1. Add recipientsTap Recipients in the Send Email step and enter the address.

Actions

FakturyRadar adds three actions to Shortcuts. Each invoice action finds the invoices itself, so a shortcut needs no separate "find" step.

Invoices from KSeF as Attachment

Returns files: PDF (one per invoice or one combined), CSV or JSON. The PDF is the official KSeF visualization with the KSeF number and QR code, generated on the device. PDF files are named after the KSeF number by default, so files in an archive never overwrite each other.

Invoices from KSeF

Returns text: a list, CSV, JSON or text in your own template. For notifications, messages and reminders.

Show Message

Shows a notification with the FakturyRadar name and icon. Tapping it opens Activity. An empty message shows nothing.

When there are no invoices, the action succeeds without a value. Check for it with "If … has no value".

Since last run

  • Returns every invoice KSeF accepted since this automation's previous run, exactly once.
  • The first run covers the last 7 days and today.
  • A skipped run loses nothing: the next one covers the whole gap.
  • If a run fails, the same invoices come again in the next one.
  • Two actions in one shortcut, such as a PDF and a notification, get the same invoices.

Dates are Polish calendar days, whatever the device's time zone.

Template

A template is text with variables in braces. The Template field comes with a working example:

Nowe faktury ({liczba}):
{#faktury}- {numer} od {sprzedawca}: {brutto}
{/faktury}Razem: {suma_brutto}

The same in English names:

New invoices ({count}):
{#invoices}- {number} from {seller}: {gross}
{/invoices}Total: {total_gross}
  • A template with invoice variables and no block repeats for every invoice: {number} | {seller} | {gross} | {due_date}
  • A {#invoices} … {/invoices} block marks the part to repeat; the text around it appears once.
  • A template without invoice variables appears once: You have {count} new invoices for {total_gross}.
  • Case, Polish letters and the choice of space, hyphen or underscore do not matter: {Due date} equals {due_date}.
  • Polish and English names always work, whatever the app's language.
  • {{ and }} print literal braces.
  • Totals are given per currency: "250,00 EUR, 123,00 zł".
  • A mistake, such as an unknown variable or an unclosed block, is reported before KSeF is contacted.

Activity

Every run of an invoice action is listed in Activity: the result, invoice summaries and, for an error, its description, the KSeF code and a suggested fix. The history stays on the device for 90 days.
